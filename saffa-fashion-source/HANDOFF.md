# Saffa Fashion — Store (developer handoff)

A single-page fashion storefront: product grid, a static circular layout, an
animated "rotating-clock" product detail view (drag/scroll/arrows to browse
products), and a slide-out cart. Ships as one self-contained HTML file.

## Stack
- React 18 + TypeScript
- Vite (dev server + build)
- Tailwind CSS + a few shadcn/ui components (in `src/components/ui/`)
- `vite-plugin-singlefile` — inlines JS/CSS into one `dist/index.html`

## Getting started
Requires Node 18+ and a package manager. This project used **pnpm**
(`pnpm-lock.yaml` included), but npm works too.

```bash
pnpm install        # or: npm install
pnpm dev            # start the dev server (http://localhost:5173)
pnpm build          # type-check + build → dist/index.html (self-contained)
```

`pnpm build` runs `tsc -b && vite build`. The output `dist/index.html` is a
single file with all JS/CSS inlined — open it directly in a browser.

## Where things live
- `src/App.tsx` — top-level composition + state (view mode, cart, focus view)
- `src/data/products.ts` — the catalogue. **Edit this to change products.**
  Each product: `{ id, name, price, category, sizes, images[], description }`.
  Images here are placeholder URLs (picsum.photos) — replace with real product
  photos. For a fully offline single file, use images embedded as `data:` URIs
  (or local imports; `vite.config.ts` inlines assets).
- `src/components/`
  - `Header.tsx` — nav, Grid/Circle toggle, cart button
  - `ProductGrid.tsx` / `ProductCard.tsx` — grid view
  - `CircleLayout.tsx` — static circular arrangement (see `ORBIT_RADIUS`)
  - `FocusView.tsx` — the rotating-clock detail view (the interesting one)
  - `CartDrawer.tsx` — cart sheet
  - `ui/` — shadcn/ui primitives
- `src/hooks/useCart.ts` — cart state (keyed by product + size)
- `src/index.css` — Tailwind + design tokens (warm-monochrome palette) +
  the focus-view rotation CSS

## FocusView — the "rotating clock" (src/components/FocusView.tsx)
Products sit on a large virtual ring whose centre is off-screen-left; the
focused product is at a fixed focal point. Rotation is driven by a
`requestAnimationFrame` physics loop (spring + inertia). Drag = grab-and-rotate
around the ring centre (pointer move/up are bound to `window`); wheel and
arrow keys also navigate. Tuning knobs at the top of the file / handlers:
- `ORBIT_DURATION` is gone (auto-orbit removed); the ring is static in browse.
- Drag feel: `pxPerStepRef` (px of drag per product) and the spring constants
  `k`/`c` in the animation loop.
- Geometry: the `geo` memo (`focalX/focalY`, `R`, item size).

## Notes
- The cart "Checkout" is a demo stub (no payment integration).
- `PREVIEW-built.html` in this zip is a pre-built self-contained output so you
  can see the target result without building. It is regenerated by `pnpm build`.
- `node_modules/` and `dist/` are intentionally excluded — run install/build.
